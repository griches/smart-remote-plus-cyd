# Smart Remote+ for CYD 0.2.1

Adds the LG webOS 26 registration recovery used by Smart Remote+: one unsigned retry on the exact certificate blacklist error or a silent initial registration, before any PIN or consent. All permissions remain present. The successful mode is stored with each TV and also used by the app picker's separate socket and imported CLI pairings.

Rejected pairing stops instead of repeatedly opening prompts. Tap OK to start a new attempt and enter the new eight-digit PIN.

Validation: PlatformIO firmware build passed; host C++ tests cover the full permission union, unchanged signed manifest and all retry-guard combinations. CLI import test passed. Clean release build excludes personal Wi-Fi and TV seed headers. OTA and factory images include SHA-256 checksums. No physical webOS 26 TV was available for firmware-specific testing.

Use the OTA image in the existing device's web updater. Use the factory image at address 0x0 for initial USB installation. The release has not flashed any user's device.
